# Aula 08

Nesta atividade foi utilizada a mesma entidade criada na **Aula 07**, mantendo o mesmo projeto iniciado na **Aula 06**.

Foram realizados:

- Criação da tabela correspondente à entidade;
- Inserção de dois registros;
- Consulta (`SELECT`) de todos os registros da tabela;
- Documentação das operações realizadas.

> **Observação:** As atividades desta aula foram realizadas no mesmo projeto da Aula 06, portanto os commits correspondentes encontram-se no histórico desse projeto.
