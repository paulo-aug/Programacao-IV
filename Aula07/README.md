# Aula 07

Nesta atividade foram desenvolvidos os requisitos solicitados para o módulo **Usuário** utilizando o mesmo projeto iniciado na **Aula 06**.

Foram implementados:

- Rotas CRUD para o módulo Usuário;
- Services responsáveis pelas operações CRUD (`pessoa.service`);
- DTOs;
- Entity de Usuário.

> **Observação:** As atividades desta aula foram realizadas no mesmo projeto da Aula 06, portanto os commits correspondentes encontram-se no histórico desse projeto.
